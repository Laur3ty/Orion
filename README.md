# Orion · Site (Front-End Design Engineering, Global Solution)

Site em **HTML, CSS e JavaScript**, versão **Layout Responsivo**, criado para a Global Solution FIAP × Citizen Tech (1TDSPR).

## Objetivo do projeto

O **Orion** é uma solução **CitizenTech** que garante que o alerta de enchente chegue a quem pode agir. Um sensor no córrego aciona luzes e sirene na rua, mesmo sem internet, e avisa pelo Telegram os vizinhos guardiões de idosos, pessoas com deficiência e crianças que não conseguem sair sozinhos. Quando o guardião confirma a retirada, a Defesa Civil vê em tempo real quem ainda está em casa. É o alerta que chega em alguém, com o cidadão mais vulnerável no centro da inovação.
